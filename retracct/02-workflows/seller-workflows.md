# Seller Transaction Workflows (S01–S06)

This document covers Seller listing-through-completion journeys, multiple offer presentation registers, and counteroffer lifecycles.

---

## S01 · Freehold Resale Listing & Sale
- **Journey:** Listing onboarding → Representation agreement (OREA Form 200) → Property disclosures → Multiple offer presentation register → Counteroffer (Form 100 / Form 810) → Acceptance → Deposit verification → Closing handoff.
- **Key Guards:** Competing offer disclosure rules under TRESA; immutable offer registration log.

## S02 · Condominium Resale Listing & Sale
- **Journey:** Listing onboarding → Ordering status certificate package → Offer presentation → Status certificate review handling → Deal firm.

## S03 · POTL / Common-Element Condo Listing
- **Journey:** Property listing with common element assessments and parcel disclosure.

## S04 · Assignment / Bank-Owned / Power of Sale
- **Journey:** Lender or original assignor listing workflow with strict disclaimer schedules and mortgage-default authority validation.

## S05 · Vacant Land / Rural / Farm Residential
- **Journey:** Boundary verification, zoning confirmation, well/septic disclosures.

## S06 · Investment / Occupied Residential
- **Journey:** Tenant notice protocols, showing scheduling compliance under the Residential Tenancies Act, lawful rent disclosures.
