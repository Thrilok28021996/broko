# Sources & Binary Reference Archive

This central repository houses all original binary source documents, executive PDFs, architectural specifications, DOCX deliverables, and workbook matrices for the BROKO platform.

All source artifacts are stored strictly outside of the 12 business modules to preserve clean module boundaries and maintain provenance.
